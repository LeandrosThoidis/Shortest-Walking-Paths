# SWaP – Shortest Walking Paths

A **Progressive Web App (PWA)** that delivers optimized campus navigation through advanced pathfinding algorithms. Published at **EDULEARN24**, SWaP transforms smartphones into intelligent navigation assistants for university environments.

## 🎯 Overview

SWaP leverages industry-standard routing algorithms including **Dijkstra's**, **A\***, and their **bidirectional variants** to compute optimal walking paths across campus. Built as a PWA, the application provides a native app-like experience with offline capabilities and full-screen functionality.

## ✨ Key Features

**Intelligent Routing**
- 🗺️ Multi-algorithm pathfinding (Dijkstra, A*, bidirectional variants)
- 🎯 Optimized for pedestrian navigation
- 🔄 Dynamic route recalculation

**Progressive Web App Capabilities**
- ⚡ Installable on any device - no app store required
- 📴 Full offline functionality after initial load
- 🖥️ Launches in standalone full-screen mode
- 📱 Native app experience in the browser

**User Experience**
- 🌍 Real-time map rendering via **Leaflet.js**
- 📍 Interactive route visualization
- 💬 Intuitive alerts and notifications (**SweetAlert2**)
- 📱 Mobile-first responsive design (**Materialize CSS**)

**Data & Customization**
- 🗺️ Powered by **OpenStreetMap** data
- 🧩 Modular architecture for easy campus adaptation
- 🔧 Configurable for any university layout

## 🛠️ Technical Stack

**Frontend**
- HTML5, CSS3, JavaScript (ES6+)
- Materialize CSS - Responsive UI framework
- Leaflet.js - Interactive mapping
- SweetAlert2 - User notifications

**Algorithms**
- Dijkstra's Algorithm
- A* Search Algorithm
- Bidirectional routing variants

**Data Source**
- OpenStreetMap (OSM) integration
